# 🤖 VK Chat Manager (Чат-менеджер для ВКонтакте)

Профессиональный, асинхронный и высокопроизводительный бот-модератор для бесед ВКонтакте, разработанный на **Python 3.14** с использованием библиотек **vkbottle** и **aiosqlite**.

---

## 🌟 Возможности и преимущества

- 👥 **4-уровневая ролевая модель**:
  - `0` — **Пользователь** (обычный участник)
  - `1` — **Модератор** (базовая модерация: кик, варны, мут)
  - `2` — **Администратор** (управление модераторами, тишина, созыв, бан-лист)
  - `3` — **Главный администратор / Создатель** (полный доступ, расформирование, админы, приветствие)
- 🎯 **Универсальный определитель целей**:
  - Ответом на сообщение (**Reply**)
  - Пересланным сообщением (**Forward**)
  - VK-упоминанием (`[id123|Иван]`, `[club123|Бот]`)
  - Ссылкой (`https://vk.com/durov`, `vk.com/id123`)
  - Текстовым ником (`@durov`, `durov`)
  - Числовым ID (`id123`, `123`)
- 🔇 **Полноценная система заглушек (/mute)**: моментальное удаление сообщений заглушенного участника для всех в беседе на заданное время (минуты, часы, дни).
- 🤫 **Режим тишины (/Тишина)**: запрет на отправку сообщений обычным участникам (модераторы и администраторы могут общаться).
- 📅 **Точная дата регистрации (/reg)**: определение момента создания страницы ВКонтакте через официальный XML FOAF-шлюз.
- 🧹 **Безопасное расформирование беседы (/demote)**: подтверждение через **интерактивные инлайн-кнопки VK** с сохранением всех модераторов и администраторов.
- 🚫 **Авто-защита от заблокированных**: при попытке забаненного пользователя вернуться по ссылке или инвайту бот моментально исключает его.
- 💾 **Асинхронная база данных SQLite**: WAL-режим, автоматическое создание таблиц и индексов.

## 📋 Таблица команд

### 🔹 Общие команды (Доступны всем)
| Команда | Алиасы | Описание |
|---|---|---|
| `/тут` | `/ping` | Проверка доступности и работоспособности бота |
| `/stata [ID]` | `/стата`, `/статистика` | Статистика участника (сообщения, варны, дата входа, роль) |
| `/reg [ID]` | `/рег` | Определение даты регистрации страницы ВКонтакте |
| `/команды` | `/help`, `/помощь` | Динамический список команд (с учетом прав вызвавшего) |
| `/number of warnings [ID]` | `/варны`, `/warns` | Просмотр количества активных варнов и истории нарушений |
| `/админы` | `/admins`, `/администраторы` | Список администрации беседы (создатель и администраторы) |
| `/модераторы` | `/moders`, `/модеры` | Список всех назначенных модераторов беседы |

### 🛡️ Команды Модератора (1-й уровень)
| Команда | Алиасы | Описание |
|---|---|---|
| `/kick [ID] [причина]` | `/кик` | Исключить участника из беседы |
| `+warn [ID] [причина]` | `/warn`, `+варн`, `/варн` | Выдать предупреждение (**3/3 — автоматический кик и бан**) |
| `-warn [ID]` | `/unwarn`, `-варн`, `/анварн` | Снять одно предупреждение |
| `/warnings in the chat` | `/варнлист`, `/warnlist` | Список всех участников беседы, имеющих активные варны |
| `/mute [ID] [время] [причина]` | `/мут` | Выдать заглушку на X минут/часов (например, `/mute @user 30m Спам`) |
| `/unmute [ID]` | `/размут`, `/снятьмут` | Досрочно снять заглушку с участника |

### ⭐ Команды Администратора (2-й уровень)
| Команда | Алиасы | Описание |
|---|---|---|
| `+moder [ID]` | `+модер`, `+moders` | Назначить участника модератором беседы |
| `-moder [ID]` | `-модер`, `-moders` | Снять полномочия модератора |
| `/Внимание [текст]` | `/внимание`, `/all` | Созвать всех участников беседы (массовый вызов) |
| `/Тишина` | `/тишина`, `/silence` | Включить/выключить режим тишины (писать могут только 1+ ур.) |
| `+ban [ID] [причина]` | `/ban`, `+бан`, `/бан` | Заблокировать пользователя в беседе (с исключением) |
| `-ban [ID]` | `/unban`, `-бан`, `/разбан` | Разблокировать участника в беседе |
| `/banlist` | `/банлист` | Посмотреть список заблокированных участников беседы |
| `/getban [ID]` | `/гетбан` | Узнать, кем, когда и за что заблокирован пользователь |

### 👑 Команды Главного администратора (3-й уровень)
| Команда | Алиасы | Описание |
|---|---|---|
| `/start` | `/старт` | Инициализация беседы и регистрация создателя |
| `+admin [ID]` | `+админ` | Выдать права Администратора пользователю |
| `-admin [ID]` | `-админ` | Снять права Администратора |
| `/приветствие [текст]` | `/welcome` | Настроить текст приветствия (`{user}` — имя, `{chat}` — беседа) |
| `/приветствие выкл/вкл` | — | Отключить или включить приветствие новых участников |
| `/demote` | `/расформировать` | Расформировать беседу (кик всех обычных участников с интерактивной кнопкой) |

## 🛠️ Пошаговая настройка ВКонтакте

### Шаг 1. Настройка группы ВКонтакте
1. Откройте страницу вашего сообщества ВК -> перейдите в **«Управление»**.
2. Вкладка **«Сообщения»**:
   - Сообщения сообщества: **Включены**.
   - Поставьте галочку: **«Разрешать добавлять сообщество в чаты»**.
3. Вкладка **«Сообщения»** -> **«Настройки для бота»**:
   - Возможности ботов: **Включены**.
   - Разрешать добавлять в беседы: **Включено**.
   - Доступ к переписке: **Разрешён** *(ОБЯЗАТЕЛЬНО, иначе бот не увидит команды участников!)*.

### Шаг 2. Получение токена доступа
1. В сообществе перейдите в **«Управление»** -> **«Работа с API»** -> вкладка **«Ключи доступа»**.
2. Нажмите **«Создать ключ»**.
3. Отметьте права:
   - ✅ **Сообщения сообщества**
   - ✅ **Фотографии**
   - ✅ **Управление сообществом**
4. Скопируйте полученный ключ (начинается с `vk1.a...`) и сохраните для файла `.env`.

### Шаг 3. Добавление бота в беседу
1. Зайдите в ваше сообщество и нажмите кнопку **«Добавить в беседу»** (или добавьте по ссылке на сообщество внутри беседы).
2. **КРИТИЧЕСКИ ВАЖНО**: Откройте список участников беседы, найдите бота и **назначьте его Администратором беседы**! Без прав администратора ВКонтакте не позволяет ботам исключать пользователей (`messages.removeChatUser`) и удалять чужие сообщения при муте/тишине (`messages.delete`).
3. В беседе напишите команду:
   ```text
   /start
   ```
   Бот зафиксирует вас как Главного администратора и приготовится к работе.

## 🚀 Установка и локальный запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/ВАШ_АККАУНТ/vk-chat-manager.git
cd vk-chat-manager
```

### 2. Создание виртуального окружения и установка зависимостей
```bash
python -m venv venv
# Linux / macOS:
source venv/bin/activate
# Windows:
venv\Scripts\activate

pip install -r requirements.txt
```

### 3. Конфигурация окружения
Создайте файл `.env` на основе шаблона:
```bash
cp .env.example .env
```
Заполните параметры в `.env`:
```env
VK_TOKEN=vk1.a.ВАШ_ТОКЕН_СООБЩЕСТВА
COMMAND_PREFIXES=/
DATABASE_PATH=chat_manager.db
DEV_IDS=123456789
```

### 4. Запуск тестов
Для проверки корректности работы всех модулей:
```bash
python tests/test_db.py
python tests/test_resolver.py
python tests/test_vk_date.py
python tests/test_rules.py
```

### 5. Запуск бота
```bash
python main.py
```

## 🌐 Развёртывание на хостинге (RuVDS / Ubuntu VPS 24/7)

Подробное руководство по установке бота на недорогой сервер под управлением **Ubuntu 22.04 / 24.04**:

### 1. Подключение к серверу по SSH
Используйте терминал или PuTTY:
```bash
ssh root@IP_ВАШЕГО_СЕРВЕРА
```

### 2. Обновление пакетов и установка Python и Git
```bash
apt update && apt upgrade -y
apt install -y python3 python3-pip python3-venv git
```

### 3. Клонирование проекта
```bash
cd /root
git clone https://github.com/ВАШ_АККАУНТ/vk-chat-manager.git
cd vk-chat-manager
```

### 4. Настройка виртуального окружения
```bash
python3 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

### 5. Создание и настройка `.env`
```bash
cp .env.example .env
nano .env
```
*(Вставьте ваш `VK_TOKEN` и нажмите `Ctrl+O`, `Enter`, `Ctrl+X` для сохранения).*

### 6. Настройка автозапуска через Systemd (24/7 с авто-перезагрузкой)
Создайте файл службы:
```bash
nano /etc/systemd/system/vkbot.service
```

Вставьте следующее содержимое:
```ini
[Unit]
Description=VK Chat Manager Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/vk-chat-manager
ExecStart=/root/vk-chat-manager/venv/bin/python main.py
Restart=always
RestartSec=5
Environment=PYTHONUNBUFFERED=1

[Install]
WantedBy=multi-user.target
```

Сохраните файл (`Ctrl+O`, `Enter`, `Ctrl+X`), затем активируйте и запустите службу:
```bash
# Перезагружаем конфигурацию systemd
systemctl daemon-reload

# Включаем автозапуск при старте сервера
systemctl enable vkbot

# Запускаем бота
systemctl start vkbot

# Проверяем статус работы
systemctl status vkbot
```

Полезные команды для управления ботом на сервере:
* `systemctl status vkbot` — статус работы бота
* `systemctl restart vkbot` — перезапуск бота (например, после обновления кода)
* `systemctl stop vkbot` — остановка бота
* `journalctl -u vkbot -f` — просмотр логов бота в реальном времени
